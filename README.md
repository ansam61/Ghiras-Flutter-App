# 🌿 غراس | Ghiras AI - تطبيق الهاتف المحمول (Flutter Standalone App)

تطبيق جوال مستقل وفائق الأداء مبني باستخدام **Flutter 3**، مصمم خصيصاً لمشروع **غراس** لرعاية النباتات وتجخيص الأمراض بالذكاء الاصطناعي، ومطابق 100% لتصاميم واجهات **Adobe XD**.

---

     مميزات التطبيق:
1. **واجهات شاشات Adobe XD كاملة**:
   - **الشاشة الافتتاحية (Splash Screen)**: هويّة زراعية باللون الأخضر والشعار الرسمي.
   - **شاشات التمهيد (Onboarding Screens)**: 3 شرائح تفاعلية بشريط تقدم وأزرار تنقل تنقل.
   - **تسجيل الدخول واستعادة الحساب (Auth)**: شاشات تسجيل الدخول، إنشاء حساب جديد، ونظام استعادة كلمة المرور.
   - **الواجهة الرئيسية (Dashboard & Home)**: ملخص حالة النباتات وحساب المسؤول `eng: ANSAM JAMEEL`.
   - **ماسح الذكاء الاصطناعي (AI Smart Scanner)**: شاشة الكاميرا والماسح الداكن مع حواف تحديد الأوراق والتحليل التلقائي.
   - **تقرير التشخيص النهائي (AI Diagnosis Report)**: إظهار كارت المرض الأحمر، نسبة المطابقة (96%)، تحليل الأسباب، والإسعاف الطارئ.
   - **موسوعة النباتات والتصنيفات (Encyclopedia)**: تصفح النباتات حسب الفئات والبحث السريع.
   - **إضافة نبتة جديدة (Add Plant)**: للتعرف على الفصائل والتخصيص المباشر.
   - **الملف الشخصي والمفضلة (Profile & Favorites)**: استعراض النباتات المفضلة والحساب.

2. **دعم كامل للغة العربية (RTL)**:
   - تم دعم اتجاه الكتابة وتنسيق الخطوط ليتلاءم تماماً مع المستخدم العربي.

3. **مشروع مستقل بحجم كامل**:
   - يمكنك فتح مجلد `ghiras_app` كمشروع مستقل في **VS Code** أو **Android Studio** وتشغيله مباشرة.

---

## 🚀 كيفية تشغيل التطبيق المستقل:

### 1. عبر السكربت المباشر:
مزدوج الضغط على ملف `RunFlutterApp.bat` الموجود داخل مجلد `ghiras_app`.

### 2. عبر سطر الأوامر (Terminal):
```bash
cd ghiras_app
flutter pub get
flutter run
```
